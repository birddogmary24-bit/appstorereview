# AppScope - 제품 요구사항 정의서 (PRD)

> 버전: 1.0
> 최종 수정일: 2026-02-25
> 작성 대상: 서비스 인수인계 담당자

---

## 1. 제품 개요

### 1.1 제품명
**AppScope** - OTT 앱스토어 리뷰 분석 통합 플랫폼

### 1.2 제품 배경 및 목적

국내 주요 OTT 서비스(티빙, 넷플릭스, 디즈니+, 웨이브, 쿠팡플레이, 왓챠)의 앱스토어 리뷰는 서비스 품질에 대한 실사용자의 즉각적인 피드백이다. 그러나 수천 건에 달하는 리뷰를 수작업으로 분석하기에는 한계가 있다.

AppScope는 다음 문제를 해결한다:

- **정보 분산**: Google Play / App Store 두 플랫폼에 리뷰가 분산되어 있음
- **분석 리소스**: 방대한 리뷰를 수작업 분석 시 과도한 시간 소요
- **인사이트 도출**: 개별 리뷰에서 서비스 개선 방향을 직접 도출하기 어려움
- **추이 파악**: 월별 감성 변화 및 이슈 급증 감지 불가

### 1.3 제품 목표

| 목표 | 측정 지표 |
|------|-----------|
| 리뷰 수집 자동화 | 6개 OTT 앱 × 주 1회 자동 수집 |
| AI 분석 정확도 | 별점 기반 카테고리 분류 100% + AI 세부 분류 |
| 인사이트 생성 | 월 1회 자동 AI 리포트 생성 |
| 서비스 비용 최소화 | 월 ₩630 이하 (Gemini + GCS 기준) |

### 1.4 대상 사용자 (페르소나)

| 구분 | 설명 |
|------|------|
| **주 사용자** | OTT 서비스 기획/운영팀 담당자 |
| **부 사용자** | UX 디자이너, 개발팀, 고객서비스팀 |
| **비기술자 고려** | 비밀번호 인증 기반의 단순 UI, 코드 수정 없이 운영 가능 |

## 2. 핵심 기능 요구사항

### 2.1 리뷰 수집 (FR-01)

| 항목 | 요구사항 |
|------|----------|
| 수집 대상 | Google Play + App Store, 6개 OTT 앱 |
| 수집 주기 | 수동(버튼) 또는 Cloud Scheduler 자동 실행 |
| 수집 한도 | Google Play 최대 1,500건 / App Store 최대 500건 (앱당) |
| 중복 방지 | `store + id` 조합으로 기존 리뷰 필터링, 신규만 분석 |
| 접근 제어 | 비밀번호 인증 필수 |

### 2.2 AI 감성 분석 (FR-02)

| 항목 | 요구사항 |
|------|----------|
| AI 모델 | Google Gemini 2.0 Flash |
| 분류 원칙 | 별점 3~5점 → 칭찬 / 별점 1~2점 → 불만 (강제 적용) |
| 세부 분류 | AI가 사전 정의된 세부 카테고리 목록에서 선택 |
| 배치 크기 | 50건/API 호출 |
| 실패 처리 | 최대 3회 재시도, 실패 시 `분석오류` 태그 부여 |
| API 없을 시 | 별점 기반 자동 분류 폴백 |

**카테고리 체계:**

| 대분류 | 세부 사유 (8가지) |
|--------|-----------------|
| 칭찬 | 오리지널 콘텐츠, 화질/재생 품질, UI 편리성, 콘텐츠 다양성, 합리적 가격, 자막/더빙 품질, 기타 칭찬 |
| 불만 | 플레이어/재생 오류, 광고 관련 불만, 요금/결제/구독, 콘텐츠 부족/불만, UI/UX 불편, 앱 안정성(크래시/버그), 자막/더빙 품질, 기타 불만 |
| 기타 | 단순 문의, 기능 제안, 미분류 |

### 2.3 통합 대시보드 (FR-03)

- 6개 앱 요약 카드 (총 리뷰 수, 긍정률, 마지막 업데이트)
- 앱별 개별 수집 버튼 및 전체 일괄 수집 버튼
- 수집 진행 상태 실시간 표시

### 2.4 앱 비교 (FR-04)

- 6개 OTT 서비스 평균 별점, 긍정/부정 비율 비교
- 카테고리별 횡단 비교 (가로 막대 차트)
- 전체/칭찬/불만 카테고리 필터 전환

### 2.5 리뷰 탐색 (FR-05)

- 카테고리, 별점, 월별 복합 필터
- 텍스트 검색 (리뷰 내용, 사용자명)
- 페이지네이션 (API 기반)
- Excel 3시트 내보내기 (월별 통계 / 세부 사유별 통계 / 전체 리뷰)

### 2.6 월간 인사이트 (FR-06)

- 분석 기간: 최근 6개월 슬라이딩 윈도우
- AI 출력 구조:
  - `summary`: 전체 트렌드 요약
  - `positiveInsights`: 칭찬 인사이트 최대 10건
  - `negativeInsights`: 불만 인사이트 최대 10건
  - `tasks`: 개선 과제 5~7건 (우선순위 + PRD 포함)
- 스파이크 감지: 이전 3개월 대비 1.5배 이상 급증 항목 플래그
- 직무 레이블 자동 부여: 개발, 기획/운영, 디자인, 고객서비스, 대외정책, 콘텐츠, 기타

## 3. 비기능 요구사항

### 3.1 성능

| 항목 | 목표값 |
|------|--------|
| API 응답 시간 (조회) | 3초 이내 |
| 리뷰 수집 타임아웃 | 300초 |
| AI 분석 속도 | 유료: 2초/배치, 무료: 6초/배치 |
| 메모리 한도 | Cloud Run 1GB |

### 3.2 보안

- 수집/분석/인사이트 생성 API는 비밀번호 인증 필수
- 비밀번호는 Salted SHA-256 해시로만 저장
- 환경변수로만 시크릿 관리 (소스코드 내 하드코딩 금지)

### 3.3 가용성

- Cloud Run 무료 티어 기준 운영 (요청 기반 스케일링)
- GCS에 데이터 영구 저장 (서버 재시작 시에도 데이터 유지)

### 3.4 비용

| 항목 | 예상 월 비용 |
|------|-------------|
| Gemini 2.0 Flash (주 1회 수집+분석) | ~₩5 |
| Gemini 인사이트 생성 (6개 앱/월) | ~₩624 |
| Cloud Run | ₩0 (무료 티어) |
| GCS | ₩0 (수 MB, 5GB 무료) |
| **합계** | **~₩630/월** |
